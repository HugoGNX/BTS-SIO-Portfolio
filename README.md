# Portfolio BTS SIO – Hugo GANGNEUX

Site statique (HTML / Bootstrap 5 / CSS), sans PHP.

## Héberger sur GitHub Pages
1. Créer un dépôt GitHub et y déposer **le contenu** de ce dossier (index.html à la racine).
2. Settings → Pages → Source : `Deploy from a branch` → branche `main`, dossier `/ (root)`.
3. Le site sera disponible sur `https://<pseudo>.github.io/<depot>/`.

## Test en local
Ouvrir `index.html` dans le navigateur (ou `python3 -m http.server`).
